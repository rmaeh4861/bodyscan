# 스트레칭 영상 파일명 규칙

`videos/<키>.mp4` 로 저장하면 자동 연결됩니다. 파일명은 아래 키와 **정확히 일치**(소문자, 확장자 mp4)해야 합니다.

권장 규격: 세로 9:16 또는 16:9, H.264 mp4, 20~40초, **10MB 이하**(GitHub 100MB 제한·모바일 로딩 고려). 압축: `ffmpeg -i 원본.mp4 -vf scale=-2:720 -c:v libx264 -crf 28 -c:a aac -b:a 96k videos/키.mp4`
