# videos 폴더 — 영상 파일명 규칙

`videos/<키>.mp4` 로 저장하면 **코드 수정 없이 자동 연결**됩니다. 파일명은 아래와 정확히 일치해야 해요(소문자, 확장자 mp4).
운동이 2개인 항목은 `<키>.mp4`, `<키>_2.mp4` 순서로 인식합니다. 파일이 없으면 카드에 “영상 준비 중”이 표시됩니다.

**권장 규격**: 세로 4:5, H.264 mp4, 20~40초, 10MB 이하

```bash
ffmpeg -i 원본.mp4 -vf scale=-2:720 -c:v libx264 -crf 28 -preset fast -an videos/키.mp4
```
